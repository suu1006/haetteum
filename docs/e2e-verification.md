# E2E 검증 및 2026-09-14 실패 수정

## 수정 내용

- HTTP 로그가 OAuth 콜백 쿼리의 `code`/`state`를 기록하던 문제를 수정했다. 로그와 Problem Details의 `instance`는 공통 `requestPath`를 통해 쿼리·fragment를 제외한 경로만 사용한다. 302/400/500 로그와 400/500 에러 응답 회귀 테스트를 추가했다.
- 인증 E2E의 공개 응답 기대값에 현재 계약의 `provider`를 추가했다. 비밀정보 미노출 검사와 공개 필드 목록 검증은 유지했다.
- 후기 E2E에 공통 정상 입력을 적용했다. 권한·중복·존재 여부 검사가 제목 누락이나 짧은 본문 때문에 조기 실패하지 않도록 수정했다. 제목 누락/본문 최소 길이 오류는 별도로 검증한다.
- 랭킹 E2E의 이미지 스냅샷을 `place_rankings`에 저장하고 저작자 표시 필드 기대값을 반영했다. 랭킹 이미지가 없을 때 `null` 반환 및 TourAPI 미호출 검증도 유지했다.

## 실행 환경

운영·개발 DB가 아닌 일회용 PostgreSQL DB를 사용한다. DB 이름은 `haetteum_tourapi_test_`로 시작해야 주간 추천과 TourAPI 실행 정책 테스트의 격리 환경 보호 조건을 모두 만족한다. 해당 테스트는 외부 TourAPI 수집을 수행하지 않는다.

테스트용 DATABASE_URL을 지정한 환경에서 다음을 순서대로 실행한다.

```sh
pnpm db:deploy
SCHEDULERS_ENABLED=false pnpm test:e2e
```

일부 테스트는 임시 스키마를 생성하고, 일부는 `public` 스키마를 사용하므로 빈 DB에서도 먼저 전체 마이그레이션을 적용해야 한다. 같은 DB에 E2E 명령을 동시에 실행하지 않는다.

배포 워크플로의 `current` 빌드에도 위 순서의 E2E 단계를 추가했다. CI DB 이름은 `haetteum_tourapi_test_ci`이며, 실패하면 후속 빌드·배포가 진행되지 않는다. 과거 `baseline` 비교 빌드는 이번 E2E 단계의 대상이 아니다.

## 검증 결과

2026-09-14 로컬 일회용 PostgreSQL 검증: **15개 suite, 103개 테스트 통과, 실패·건너뜀 0개**. 이전 실패 18건이 해소됐으며, 이전에 격리 DB 조건으로 건너뛴 8건과 신규 입력 오류 테스트 2건도 포함한다.

운영·개발 DB에 대한 마이그레이션이나 배포는 실행하지 않았다. GitHub Actions 원격 실행 결과는 별도로 확인해야 한다.
