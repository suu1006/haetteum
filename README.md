# Haetteum

Next.js 16 App Router 기반 웹 애플리케이션입니다.

## 요구사항

- Node.js 20.9.0 이상
- pnpm 10.33.0

## 시작하기

의존성을 설치하고 개발 서버를 실행합니다.

```bash
pnpm install
pnpm dev
```

브라우저에서 [http://localhost:3000](http://localhost:3000)을 엽니다.

## 명령어

```bash
pnpm lint
pnpm build
pnpm start
```

- `pnpm lint`: ESLint 검사를 실행합니다.
- `pnpm build`: 프로덕션 빌드를 생성합니다.
- `pnpm start`: 생성한 프로덕션 빌드를 실행합니다.
